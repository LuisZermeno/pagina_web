# Nexflow Ops — Landing Page de Automatización B2B

Esta es la estructura web completa para la propuesta de valor de **Automatización de Procesos Operativos y Datos B2B**.

## 🚀 Arquitectura y Referencias de Diseño
El diseño sigue el estándar moderno de agencias B2B y SaaS de alto rendimiento (inspirado en referencias como *Flow Ninja*, *Retool* y *Front*):

1. **Enfoque en el Problema/Dolor:** En lugar de hablar de "código Python", se enfoca en "horas perdidas", "limpieza de reportes" y "eliminación de errores humanos".
2. **Sección Interactiva de Comparación:** Incluye un componente visual arriba del pliegue (Hero Demo) que muestra el contraste entre un proceso manual de 12 hrs/semana vs. la ejecución del script automático en 3 segundos.
3. **Estilo Moderno & Minimalista:** Paleta de colores *Dark Mode* (`#0A0D14`, `#121824`) con acentos en azul cian (`#38BDF8`) e índigo, tipografía legible (`Inter` + `JetBrains Mono` para bloques técnicos) e iconos vectoriales (`Lucide`).
4. **Llamado a la Acción (CTA) Claro:** Dirigido a agendar un "Diagnóstico Operativo Gratuito de 15 minutos".

## 📁 Archivos Incluidos
- `index.html`: Página web completa responsive (HTML5 + CSS3 + JS inline) lista para desplegar en Netlify, Vercel o GitHub Pages.

## 🛠️ Cómo Probar o Modificar la Página
1. Descarga el archivo `index.html`.
2. Haz doble clic para abrirlo en cualquier navegador web (Chrome, Firefox, Edge, Safari).
3. Para cambiar textos, colores o correos de contacto, simplemente abre el archivo en cualquier editor de texto (como VS Code).
